================================================================================
                          WHAT IS SARVAGYA?
================================================================================

Sarvagya is a professional web application that:

1. Lets users upload trading charts
2. Uses AI (Google Gemini 2.5 Flash) to analyze them
3. Provides technical analysis in a conversational interface
4. Maintains context for follow-up questions

Result: Real AI-powered trading chart analysis, not fake data.

================================================================================
                         4-MINUTE DEMO FLOW
================================================================================

1. SHOW EMPTY STATE (20 sec)
   Say: "This is Sarvagya - an AI research assistant for trading charts"
   Show example prompts

2. UPLOAD CHART (30 sec)
   Click attachment button
   Select a trading chart (PNG/JPG/WebP)
   Show preview

3. ASK QUESTION (20 sec)
   Type: "Analyze this chart and explain the market structure"
   Press Ctrl+Enter or click Send

4. SHOW ANALYSIS (60 sec)
   Wait for response (5-15 seconds typical)
   Read key findings aloud
   Emphasize: "This is REAL AI analysis from Gemini"

5. FOLLOW-UP (30 sec)
   Type: "What would invalidate this setup?"
   Show it understands context without re-uploading

6. RESET (20 sec)
   Click "New Chat"
   Show clean slate

Total Time: 3-4 minutes
Impact: Judges see real intelligence + professional execution

================================================================================
                      QUICK TROUBLESHOOTING
================================================================================

"Backend offline"
  → Make sure backend is running
  → Check terminal for errors
  → See README.md for full troubleshooting

"API key not configured"
  → API key is already set in launcher
  → Or set GOOGLE_API_KEY environment variable

"Port in use"
  → Something is using port 3000 or 8000
  → Restart computer or close other services

"npm not found"
  → Install Node.js from nodejs.org
  → Then run setup script again
