## HOW TO RUN

STEP 1: Setup (one-time)
  Windows: setup.bat
  Unix/Mac: bash setup.sh

STEP 2: Start Backend (Terminal 1)
  cd backend
  export GOOGLE_API_KEY=your-api-key  (or set on Windows)
  source venv/bin/activate
  python main.py

STEP 3: Start Frontend (Terminal 2)
  cd frontend
  npm run dev

STEP 4: Open Browser
  http://localhost:3000

## REAL AGENT INTEGRATION

✓ Uses Google ADK with Gemini 2.5 Flash model
✓ Real chart analysis - NOT hardcoded responses
✓ Multimodal support - Chart images + text prompts
✓ Conversation context - Full history maintained
✓ Error handling - Graceful fallbacks with safe messages

Agent Flow:
  1. User uploads chart (PNG/JPG/WebP)
  2. Frontend validates: type, size < 10MB
  3. POST /api/chat with multipart form data
  4. Backend validates and creates session
  5. Agent adapter invokes Google ADK LlmAgent
  6. Gemini 2.5 Flash analyzes chart
  7. Real response returned to frontend
  8. No fake or hardcoded data

## TROUBLESHOOTING

Issue: Backend offline
  Solution: Check backend is running on localhost:8000

Issue: API key not configured
  Solution: Set GOOGLE_API_KEY env var or add to backend/.env

Issue: Can't connect frontend to backend
  Solution: Check CORS is enabled (it is by default)

Issue: Chart upload fails
  Solution: Verify PNG/JPG/WebP, file size < 10MB

Issue: Agent analysis is slow
  Solution: Expected (5-15 seconds), first request slower
