# Sarvagya Frontend

React frontend for Sarvagya AI trading chart analysis.

## Setup

```bash
cd frontend
npm install
npm run dev
```

## Development

Frontend runs on port 3000 by default and proxies API requests to the backend on port 8000.

## Features

- Clean, professional chat interface
- Chart image upload (PNG, JPG, WebP)
- Real-time agent analysis
- Loading states and error handling
- Responsive design for desktop and mobile
- Example prompts and empty state
- Disclaimer for responsible trading positioning

## Architecture

Built with React and Vite. Minimal dependencies for fast performance.
